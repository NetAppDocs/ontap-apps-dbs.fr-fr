= Sauvegardes optimisées pour les snapshots de stockage
:allow-uri-read: 


[role="lead"]
Oracle Snapshot Optimized Backups était une méthode de restauration à un point précis dans le temps qui permettait à un utilisateur d'effectuer une restauration à l'aide d'instantanés sans placer la base de données en mode de sauvegarde à chaud.

Les utilisateurs peuvent toujours restaurer des données à partir d'instantanés sans utiliser le mode de sauvegarde, mais seule la restauration complète via RECOVERY AUTOMATIC est prise en charge. La restauration incomplète à l'aide de la méthode SNAPSHOT TIME permet d'indiquer la date et l'heure de création de l'instantané.
